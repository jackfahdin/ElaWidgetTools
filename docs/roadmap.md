# 维护与路线图

[返回首页](../README.md) · [组件目录](components.md) · [参与贡献](contributing.md)

## 分支定位

本仓库以 [Liniyous/ElaWidgetTools](https://github.com/Liniyous/ElaWidgetTools) 的代码为基础，开展独立开发与维护。现有代码基线对应上游提交 `aae58f5`（ElaWidgetTools V3.0 重构初步版本）。

[RainbowCandyX/ElaWidgetTools](https://github.com/RainbowCandyX/ElaWidgetTools) 是文档组织方式的参考。本仓库与其代码基线和后续演进不同，不沿用其组件数量、平台验证结论或附加功能声明。

上游的介绍、发布版本与 API 文档可供参考；本分支的接口、兼容性与维护范围以当前仓库为准。

## Qt 版本策略

**后续仅维护 Qt 6.12.0 及以上版本，以 Qt 6.12.0 为最低维护目标。**

- Qt 5 和 Qt 6.12.0 以下版本不在后续维护范围内。
- 现有源码中的旧版本兼容分支将在迁移阶段评估，不代表继续提供旧版支持。
- 新版 Qt 是否通过验证，需要以届时的构建与运行结果为准；维护范围不等于所有未来版本已经验证。

这一策略目前是迁移目标。当前顶层 [CMakeLists.txt](../CMakeLists.txt) 仍查找 Qt 5 / Qt 6，并明确拒绝高于 Qt 6.7.0 的版本，因此**尚不能按现有配置直接构建 Qt 6.12.0 版本**。

## 平台计划

| 平台 | 现有基础 | 后续重点 |
| --- | --- | --- |
| Windows | 上游已有窗口处理和 DXGI 采集实现 | 验证新 Qt 版本下的窗口行为、主题效果与部署 |
| Linux | 上游已有支持，原文档提及 Ubuntu / Kylin | 建立构建基线，验证窗口交互与运行时依赖 |
| macOS | 尚未完成本分支适配与验证 | 评估构建、原生窗口行为、显示缩放与应用打包 |

平台支持按实际完成的验证逐步公布。当前不声明任何平台已通过 Qt 6.12.0 及以上版本的验证。

部分能力具有平台限制：例如 `ElaDxgiManager` 依赖 Windows 的 DXGI，不能直接作为 Linux 或 macOS 的屏幕采集实现。

## 推进顺序

### 第一阶段：建立独立维护入口

- 明确本仓库与上游、参考分支的关系。
- 整理中文首页、组件索引和贡献说明。
- 公布 Qt 版本策略与平台计划。

### 第二阶段：迁移构建并验证

- 将 Qt 最低版本要求调整为 6.12.0，检查旧版条件编译与新版本 API 差异。
- 整理 Qt 路径配置、依赖发现、安装目录和示例构建。
- 检查 `WidgetsPrivate` 等私有接口依赖，评估 Qt 升级带来的兼容性影响。
- 在 Windows、Linux 上建立可复现的构建与运行验证流程。
- 根据实际验证结果补充编译、集成和部署指南。

### 第三阶段：推进 macOS 适配

- 拆分 Linux 与 macOS 的构建选项；当前非 Windows 分支中的链接选项不能直接视为适用于 macOS。
- 验证无边框窗口、标题栏、菜单、焦点、弹出层与高分屏表现。
- 明确平台专属功能的可用范围，并完善应用打包与依赖部署。
- 完成验证后更新支持矩阵，再标记为正式支持。

上述阶段表示工作顺序，不承诺发布日期。具体编译配置和功能改动将在后续开发中落实。
