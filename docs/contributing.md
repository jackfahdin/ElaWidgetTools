# 参与贡献

[返回首页](../README.md) · [组件目录](components.md) · [维护与路线图](roadmap.md)

本仓库独立维护，欢迎通过本仓库的议题（Issue）反馈问题、提出建议，通过合并请求（PR）参与改进。文档与讨论优先使用中文。

## 反馈问题

为了方便复现，请尽量提供：

- 操作系统及版本、CPU 架构。
- Qt、编译器和 CMake 版本，以及所用的仓库提交。
- 最小复现代码或操作步骤。
- 预期结果、实际结果及相关日志；界面问题可附截图。

当前已完成 Linux / Qt 6.12.0 的构建与基础运行验证，macOS 仍处于规划阶段。反馈时请区分现有代码问题与适配需求，版本和平台状态见[维护与路线图](roadmap.md)。

## 提出功能建议

说明希望解决的使用场景、现有组件的不足与预期交互。涉及新组件、公共接口调整或平台专属能力时，建议先通过议题讨论范围。

## 提交改进

1. 保持单次改动聚焦，说明要解决的问题与行为变化。
2. 沿用相关代码的命名与风格，公共接口变化同步更新文档和示例。
3. 附上实际使用的 Qt 版本、操作系统和验证结果；未验证的平台请明确说明。
4. 保留原有版权与许可声明，不提交本机路径、构建产物或无关文件。

后续代码改动以 Qt 6.12.0 及以上版本为维护目标。具体编译与验证范围见[编译指南](build.md)。

## 代码风格与检查

仓库提供 EditorConfig、clang-format、cmake-format 和 clang-tidy 配置。工具版本、安装方法与手动命令见[代码风格与静态分析](code-style.md)。现有 C++ 与 CMake 文件已建立统一格式基线，后续检查本次修改的文件；格式整理与功能修改分别提交。静态分析目前作为人工审查参考，不接入默认构建。
