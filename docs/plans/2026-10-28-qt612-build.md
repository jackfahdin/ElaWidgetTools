# Qt 6.12 构建迁移计划

目标：使用本机 Qt 6.12.0 完成组件库和示例的配置、编译、启动及安装引用验证，以 CMake Presets 作为构建入口。

## 构建方案

- 仓库维护 Linux Debug / Release 预设，采用 Ninja，输出到 `build/<预设名>`，安装到 `install/<预设名>`。
- 通用预设通过环境变量 `QT_ROOT` 接收 Qt 安装路径。本机路径放入被忽略的 `CMakeUserPresets.json`，使用 `local-linux-debug` / `local-linux-release`。
- CMake 最低版本设为 3.25，Qt 最低版本设为 6.12.0，继续使用 C++17。
- 用目标级依赖替代 Qt 5 / Qt 6 混合查找，保留动态库、静态库和可选示例构建。
- 仅修复编译与验证中暴露的兼容问题；macOS 的完整适配另行开展。

## 验证结果

- 使用本机 Qt 6.12.0 完成 Linux Debug、Release 动态库和示例构建，另验证静态库构建。
- Debug 示例与安装后的 Release 示例在 Xvfb 下分别运行 12 秒、10 秒，均输出初始化成功，由超时命令结束（退出码 124）。
- 安装后的动态库、静态库分别通过独立消费项目验证，涵盖资源与字体加载、图标码点、主题切换、选项卡绘制和正常退出（退出码 0）。
- 通用预设通过 `QT_ROOT` 找到 Qt 6.12.0；指定 Qt 6.11.1 时配置按预期失败。
- 独立代码审查未发现阻塞问题；源码遗留的弃用接口警告、Qt 私有接口依赖和平台验证边界已记录在编译指南。
